Privacy Policy

Terakhir diperbarui: Juli 2026

AaaaKetahuan ("aplikasi", "kami") menghormati privasi Anda. Halaman ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi data Anda saat menggunakan aplikasi pencatatan keuangan pribadi ini.

1. Data yang Kami Kumpulkan

1.1 Data Transaksi Keuangan

Semua data transaksi yang Anda masukkan ke dalam aplikasi — termasuk nominal, kategori, tanggal, deskripsi, metode pembayaran, dan sumber pemasukan — disimpan secara lokal di perangkat Anda dalam format file JSON.

1.2 Data Akun Google

Jika Anda memilih fitur sinkronisasi Google Sheets, aplikasi akan mengakses:

  • Alamat email — untuk mengidentifikasi akun Google Anda
  • Google Spreadsheet — untuk menyimpan salinan data transaksi Anda ke spreadsheet pribadi di Google Drive Anda (hanya jika Anda memberikan izin) — baca, edit, buat, hapus

Kami tidak mengumpulkan:

  • Lokasi GPS
  • Kontak atau daftar teman
  • Foto atau media
  • Riwayat browsing
  • Data biometrik

2. Bagaimana Data Digunakan

  • Data transaksi lokal — hanya digunakan untuk menampilkan laporan keuangan, grafik, dan riwayat di dalam aplikasi
  • Data Google Sheets — hanya digunakan untuk menyinkronkan data transaksi Anda ke spreadsheet pribadi Anda di Google Drive. Kami tidak pernah membaca spreadsheet Anda yang lain.

3. Penyimpanan & Keamanan

  • Data transaksi disimpan di context.filesDir perangkat Anda — tidak dapat diakses oleh aplikasi lain tanpa root
  • Token OAuth dikelola oleh GoogleAccountCredential dan AccountManager Android — diperbarui secara otomatis oleh Google Play Services
  • Tidak ada data yang dikirim ke server pihak ketiga selain Google Sheets API (jika fitur sinkronisasi diaktifkan)

4. Berbagi Data dengan Pihak Ketiga

Kami tidak menjual, menyewakan, atau membagikan data Anda kepada pihak ketiga mana pun. Satu-satunya transfer data terjadi saat Anda mengaktifkan sinkronisasi Google Sheets, di mana data dikirim langsung dari perangkat Anda ke Google Sheets API — tidak melalui server perantara kami.

5. Kontrol & Hak Pengguna

  • Anda dapat menghapus semua data lokal kapan saja melalui Pengaturan → Hapus Data
  • Anda dapat memutuskan koneksi Google Sheets kapan saja melalui Pengaturan → Spreadsheet & Sync
  • Anda dapat mencabut izin akses aplikasi melalui Google Account Permissions

6. Retensi Data

Data lokal disimpan hingga Anda menghapus aplikasi atau menghapus data melalui pengaturan. Data di Google Sheets tetap berada di Drive Anda bahkan setelah aplikasi dihapus — Anda dapat menghapus spreadsheet tersebut secara manual.

7. Perubahan pada Kebijakan Ini

Jika ada perubahan signifikan, kami akan memberi tahu melalui pembaruan aplikasi. Kebijakan ini diperbarui pada Juli 2026.

8. Kontak

Jika ada pertanyaan tentang privasi data, hubungi kami melalui email yang tercantum di halaman Google Play Store.
